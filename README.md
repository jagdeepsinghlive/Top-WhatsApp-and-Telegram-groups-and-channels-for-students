# Top WhatsApp and Telegram Groups and Channels for Students

A mobile-friendly student community directory for Telegram channels and WhatsApp channels covering SSC, RRB, JEE, NEET, UPSC, CTET/TET, CUET, JKBOSE, JKSSB, IIT JAM, CSIR NET, GATE, school notes, GK and education updates.

## Features
- Search and category filters
- Direct Telegram and WhatsApp buttons
- Responsive mobile-first UI
- SEO title, description, canonical URL and CollectionPage schema
- robots.txt and sitemap.xml
- Easy JavaScript data list for future updates

## GitHub Pages
Enable **Settings → Pages → Deploy from a branch → main → / (root)**.

Content links are provided for discovery. Availability and channel content can change.
